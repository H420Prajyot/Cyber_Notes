## 🚀 Why I Created This

During security assessments, I often found myself switching between different notes, commands, testing guides, and checklists.

This project is my attempt to organize those resources into a **single, practical security knowledge hub**.

The goal is simple:

> **Find the methodology → Find the test case → Perform the test → Collect evidence → Report the finding.**

The resources will continue to evolve as I learn, research, and discover new testing techniques.

---

## ⚠️ Responsible Use

These resources are intended for:

- Authorized penetration testing
- Vulnerability assessments
- Security research

- Defensive security validation
- Educational purposes
